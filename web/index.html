首页 / API 文档

API 文档

为社区服务器提供已确认、公开且仍有效的记录。

接口版本 v1 · 文档更新 2026-10-12

当前网站仅在本地预览。线上接入需要使用运营方提供的 HTTPS 地址，并遵守页脚中的名单接入条款。

获取有效名单

GET /api/v1/bans

未设置接口密钥时可读取；运营方配置接口密钥后，请在请求头传递凭证。不要把密钥放进网页脚本或链接参数。

Authorization: Bearer <你的接口密钥>
{
  "version": 1,
  "generatedAt": "<UTC 时间>",
  "cacheHours": 24,
  "bans": []
}

上述为空列表的结构示例，不表示网站当前名单结果。每条名单记录包含以下字段：

steamId
SteamID64 字符串，必须按字符串保存，避免整数精度损失。
reason
管理员记录的判定原因。
expiresAt
到期时间字符串；null 表示没有设置到期时间。
caseId
用于查询证据与处理过程的案件编号。

仅导出状态为已确认、公开、SteamID64 合法且未到期的记录。同一账号存在多个有效案件时，输出覆盖期限较长的一条；永久记录优先。

待审核、讨论、待自证、申诉中、撤销、隐藏、无效及到期记录均不导出。网站不会直接连接游戏服务器执行处罚。

查看当前名单 JSON

公开查询

GET /api/v1/players?q=昵称&status=active&page=1&size=20
GET /api/v1/player/{案件编号}
GET /api/v1/profiles/{SteamID64}?group=all&page=1&size=20
GET /api/v1/statistics
GET /api/v1/communities
GET /api/v1/announcements
GET /api/v1/report-categories

列表查询每页最多 50 条，支持昵称、SteamID64 或案件编号。账号汇总支持 all、active、expired、pending、resolved 分组，每页最多 50 条；摘要计数只涵盖公开且账号完全相同的案件。公开案件查询不会返回隐藏记录；社区公开目录不包含申请人的联系方式。

缓存、错误与重试

推荐每日下载一次，缓存 24 小时，与联合社区预留插件的接入格式兼容。成功获取新列表后完整替换缓存，并停止使用已撤销、隐藏、申诉中或到期的旧记录。

401
缺少或错误的凭证。检查请求头，避免连续重试。
403
权限、会话或来源校验失败。
404
资源不存在，或未向当前访问者公开。
429
达到请求限流。响应含 Retry-After 时按该时长等待，否则逐步延长重试间隔。
503 / 网络失败
保留故障状态，不能把错误响应当作空名单或新确认结果。

通用 API 请求有频率限制，名单下载有额外限流。写入需要登录、同源 Origin 与 X-CSRF-Token；公开名单密钥不会授予管理权限。
