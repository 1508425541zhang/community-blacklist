# 联合社区黑名单网站

仅本地运行：http://127.0.0.1:8089/ ，独立后台 `/admin`。已从管理站撤下，不自动部署。

Go 后端 + SQLite 数据库 + 原生 JavaScript 前端。参考 BFBAN 的公开布局及案件处理流程，使用独立品牌、代码和数据。

已支持玩家查询／筛选／分页、举报、证据链接、案件详情与时间线、讨论、审核投票、申诉、社区审批、公告、账号权限、审计和名单 API。普通用户与审核员仅Steam登录，密码账号仅管理员。

运行、数据库迁移、备份、权限及未配置的外部能力见 [OPERATIONS.md](OPERATIONS.md)。测试 `go test ./...`，构建 `go build .`。环境变量示例见 `.env.example`，运行程序不会自动读取这个文件。

初始化凭证只保存在私密文件，请勿提交到版本库。未确认案件不进入服务器名单；此网站部署不自动打开 Warcon 的预留导入插件。
